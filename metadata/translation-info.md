# Aperto Bible — Translation Info

## Project

- **Name:** Aperto Bible (Aperto Bibel)
- **License:** CC BY-SA 4.0
- **Format:** USFM 3.0
- **Source Text:** Nestle-Aland Novum Testamentum Graece (NA28) for NT; Biblia Hebraica Stuttgartensia (BHS) for OT
- **Translation Approach:** Dynamic equivalence with extensive footnoting

## Translation Methodology

1. **AI-Assisted Drafting** — Initial translations are generated using AI tools, working from the original language text
2. **Human Review** — Every chapter is reviewed for accuracy, readability, and faithfulness
3. **Cultural Annotation** — Footnotes are added to bridge cultural gaps between the ancient world and modern readers
4. **Community Feedback** — Open pull requests allow anyone to suggest improvements
